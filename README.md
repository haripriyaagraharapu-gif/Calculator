Advanced Calculator Web App

A modern and interactive calculator web application built using HTML, CSS, and JavaScript.
This project includes scientific-style features, voice input, dark/light mode, responsive design, keyboard support, and calculation history storage.

Features
Basic arithmetic operations
Scientific-style calculator UI
Dark / Light theme toggle
Voice input support
Keyboard support
Calculation history
Local storage history saving
Responsive mobile-friendly design
Interactive hover animations
Glassmorphism modern UI
Delete last character option
Error handling

Voice Input Usage

Click the 🎤 Voice button and speak expressions like:

“eight plus nine”
“seven multiplied by five”
“ten divided by two”

The calculator converts speech into mathematical expressions automatically.

Keyboard Shortcuts
Key	Action
0–9	Numbers
+ - * /	Operators
Enter	Calculate
Backspace	Delete
Escape	Clear Display
